# NHC Workflow Automation — Capstone Website

A responsive, self-contained static website (HTML, CSS, JavaScript) for Kennesaw State University NHC Team 1.

## Preview
Open `index.html` in a browser. Internet access is optional; if available, Google Fonts will load, otherwise system fonts are used.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`.
5. Save and open the provided public URL once published.

You can also drag the folder into Netlify Drop (https://app.netlify.com/drop) to publish.

## Editing
- `index.html`: text, team members, milestones, tests, and diagrams.
- `styles.css`: colors, layout, responsive styling.
- `script.js`: mobile menu, milestone tabs, QA environment filters, active navigation.
